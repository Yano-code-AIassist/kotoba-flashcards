# 資料からAIで単語を生成する

単語の一覧で「資料からAIで生成」を開き、ファイル・URL・テキストを指定します。例えば、基本情報技術者の「基礎理論」フォルダーで授業資料を指定すると、そのフォルダーへ登録する問題・答えの候補を作れます。

## 利用手順

1. 単語帳を作成し、単語の管理画面または登録先のフォルダーを開きます。
2. 「資料からAIで生成」で資料と語数の目安（5・10・20・30語）を指定します。
3. 「単語を生成する」を押します。資料の内容をGoogle Gemini APIへ送信します。
4. 問題・答え・補足を元の資料と照合し、必要なら編集します。不要な候補のチェックを外せます。
5. 「○語を登録する」でログイン中のアカウントへまとめて保存します。

生成直後は未登録です。補足には出典と「資料内の根拠（AI抽出）」を入れますが、引用や答えの正しさを保証するものではありません。AIが資料中の指示に従わないよう指示し、回答形式・件数・文字数を検証しています。正確さは登録前に確認してください。

同じ問題・答え・補足の組は初期設定で重複を除外します。対象は追加先フォルダーです。保存エラー時は生成内容を保持し、別端末での更新が検出された場合は登録を止めます。

## 対応する資料

| 入力     | 対応・上限                                                                                          |
| -------- | --------------------------------------------------------------------------------------------------- |
| ファイル | PDF、TXT、Markdown、CSV。1回1ファイル・5MB以下。Word・PowerPointはPDFへ書き出して使用               |
| URL      | ログイン不要の公開Webページ、上記形式の公開資料。HTTP/HTTPSの標準ポートのみ。5MB・15秒・転送3回まで |
| テキスト | 20〜50,000文字。TXT・MD・CSVとWebページから読み取る本文にも同じ上限を適用                           |
| 生成数   | 最大30語。資料の情報が少なければ指定数より少なくなる場合あり                                        |

TXT・MD・CSVとWebページ本文はUTF-8で読み込みます。本文がJavaScript実行後に表示されるサイト、ログインが必要なページ、動画そのものは対象外です。読み取れない場合は本文をテキスト欄へ貼り付けてください。

PDFは図表も含むファイル入力としてAPIへ渡し、テキストファイルとWebページはサーバーで本文へ変換して渡します。元資料は当アプリのDBやディスクには保存しません。登録を確定した単語だけを、通常のアカウント保存に追加します。

Gemini APIの無料枠では、送信した内容がGoogleの製品改善に利用される条件になっています。個人情報、学校や企業の非公開資料、契約書などは送信しないでください。有料枠は料金表上「製品改善に利用しない」と区別されています。詳しくは下記の公式料金ページを確認してください。

## 管理者の設定

現在の接続方式はGoogle Gemini APIです。既定モデルは、資料の解析と構造化出力に対応する安定版 `gemini-3.5-flash-lite` です。公式料金表では入力・出力とも無料枠があります。ただし無料枠は無制限ではなく、利用できる回数・トークン数はプロジェクトや時期により変わります。現在の上限はGoogle AI Studioの「Rate limits」で確認してください。

APIキーが未設定なら「AI機能の準備が必要です」と表示し、生成は実行しません。通常の手動追加・CSVは利用できます。

プロジェクト直下の `.env` に以下を設定して開発サーバーを再起動してください。キーをチャットやソースコードへ貼らず、`VITE_` を付けた環境変数にも入れないでください。

```dotenv
GEMINI_API_KEY=ここに管理者のAPIキーを設定
GEMINI_MODEL=gemini-3.5-flash-lite
AI_USER_DAILY_LIMIT=10
AI_GLOBAL_DAILY_LIMIT=50
```

```powershell
npm run dev
```

APIキーは[Google AI StudioのAPIキー画面](https://aistudio.google.com/apikey)で作成します。公開サーバーでは同じ値をホスティング先の環境変数に設定します。APIキーはサーバーだけで使い、ブラウザーには返しません。モデルを変更する場合は、Gemini APIのファイル入力とStructured Outputsに対応し、無料枠があることを公式料金表で確認してください。

日次上限はUTC基準で、生成の試行回数です。開始後の失敗・中止も含みます。回数をDBへ保存するためサーバー再起動や複数サーバーでも共有します。同一アカウントの同時生成は1件、各サーバープロセスの同時生成は2件までです。回数制限は料金の絶対上限ではありません。

## 実Geminiの5語生成テスト

次のコマンドは、基本情報技術者向けに自作した163文字の文章から5語を生成します。個人情報や既存教材は送信しません。

```powershell
# APIへ送信せず、文章・語数・検査対象だけを確認
npm run ai:smoke -- --dry-run

# .envのGEMINI_API_KEYを使って実Geminiへ送信
npm run ai:smoke
```

生成後は次の条件を自動判定し、結果と生成内容を `.artifacts/ai-smoke-日時.json` に保存します。

- 指定どおり5語ある
- 問題・答え・補足に空欄がない
- 同じ問題と答えの重複がない
- 各候補の引用が元文章に実在する
- CPU、主記憶装置、キャッシュメモリ、OS、IPアドレスを網羅する

自動判定は形式と根拠の有無を確認するものです。例えば「CPUは命令を解釈する」という引用が元文章に存在することは確認できますが、質問として分かりやすいかは生成レポートを人が読んで最終確認します。APIキーはレポートやログへ出力しません。

## 検証範囲

- APIを実行する前に、ログイン・アカウントID・Originを照合します。
- URLはDNS解決結果を検証し、検証済みIPへ接続します。内部ネットワーク・ループバック・リンクローカルへの接続や、そのような転送を拒否します。
- 元資料中のHTMLは画面へ挿入せず、生成内容はReactのテキストとして表示します。
- API応答とURL取得を代替した自動テストに加え、上記のスモークテストで実Geminiの形式・引用・重要語を検査できます。実通信には管理者のAPIキーが必要です。
