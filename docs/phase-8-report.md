# Phase 8：検索・絞り込み・一括登録・CSV

## 1. 実装した内容

単語管理で、必要な単語を検索して編集し、教材を貼り付けやCSVからまとめて追加できるようにしました。スマートフォンのカード一覧とPCのテーブル一覧で共通に使えます。

### 検索・学習状態の絞り込み

- 問題・答え・補足説明の部分一致検索に対応しました。
- NFKC正規化と小文字化を検索時だけ適用し、英字の大文字・小文字と全角・半角の差を吸収します。保存する本文は変更しません。
- 空白で区切った検索語はAND条件です。例えば `RFP 提案` は、問題「RFP」、補足「提案依頼書」に一致します。
- 「すべて／未学習／覚えた／まだ」を検索と組み合わせられます。表示数・全件数、条件解除、該当なしの案内を用意しました。
- PCの「保存して次へ」は表示中の順序を使います。編集によって検索対象から外れた場合も、保存して終了すると検索欄へ操作位置を戻します。
- 下書きを保護するため、行の編集中は検索条件の変更・取り込み・出力を停止します。

### 一括貼り付けと登録前の確認

```text
RFP | Request for Proposal | 提案依頼書
RFI | Request for Information | 情報提供依頼書
SoR | Systems of Record | 記録を管理するシステム
```

1行を1語として扱い、補足は省略可能です。空行は無視し、項目の前後の空白を除きます。項目中に `|` や改行を含めたい場合はCSVを利用します。

「プレビューを表示」で、元の行番号・3項目の内容・エラー・重複を確認できます。20行ずつページを切り替え、長い本文も省略せず読めます。横に収まらない表はダイアログ内だけをスクロールします。

問題・答えの必須、問題・答え各2,000文字／補足5,000文字、項目数を検証します。エラーが1行でもある場合は全件の登録を停止し、元の入力を修正して再度プレビューします。入力変更で古いプレビューは解除します。

初期設定では、問題・答え・補足がすべて一致する重複を除外します。選択した単語帳と入力内の両方を調べます。重複比較は前後空白を除いた完全一致で、検索とは異なり英字の大小や全半角を区別します。チェックを外すと重複も追加できます。すべて重複の場合は登録ボタンを無効にします。

### CSVの仕様

| 項目 | 内容 |
| --- | --- |
| 対象 | 問題・答え・補足説明の教材データ |
| 含めない情報 | ID・学習状態・最終学習日時・作成／更新日時・学習セッション |
| 列の順序 | 問題、答え、補足説明。補足を省いた2列も可 |
| 見出し | 日本語 `問題,答え,補足説明` または英語 `question,answer,note`。補足列名は `補足` も可 |
| 見出しなし | 利用者が「先頭行は見出し」のチェックを外して指定 |
| 文字コード | 読み込みはUTF-8（BOMあり／なし）またはShift_JISを選択。出力はUTF-8 BOM付き |
| 改行 | CRLF・LF・CRを読み込み、出力のレコード区切りはCRLF |
| 特殊文字 | 引用符内のカンマ・改行、二重引用符のエスケープに対応 |
| 出力範囲 | 単語帳の全件、または検索・学習状態で絞り込んだ表示中の単語 |
| 取り込み上限 | 1回500語・100万文字、CSVファイルは2MB（2,097,152バイト）以下 |

例えば、問題が `TCP,UDP` の場合はCSV上で `"TCP,UDP"` とします。単純なカンマ分割では2項目に分かれてしまうため、引用符の内側かどうかを判定する解析処理をサービスに分離しました。引用符・改行の扱いの確認元：[RFC 4180](https://www.rfc-editor.org/info/rfc4180/)。

文字コードの選択は `TextDecoder` に渡し、`fatal: true` で不正なバイト列をエラーにします。空ファイル、読めない文字、閉じていない引用符、列数や見出しの不正も、アプリを停止させず画面に理由を表示します。確認元：[MDN：TextDecoder](https://developer.mozilla.org/en-US/docs/Web/API/TextDecoder)。

表計算ソフトで数式と解釈されやすい `= + - @` とその全角文字で始まる内容は、出力時に引用符内でタブを付けます。アプリ内の本文は変更せず、再取り込みでは共通の前後空白除去でタブを取り除きます。対策の参考：[OWASP：CSV Injection](https://community.owasp.org/attacks/CSV_Injection)。表計算ソフトや再保存による動作差があり、すべての環境で数式実行を防ぐ保証はしません。

### 保存と下書きの保護

- プレビューでは保存せず、確認後に全行を再検証して1回の保存で追加します。
- 新しいIDを割り当て、未学習・最終学習日時なしで登録します。既存の単語と学習途中の出題順は維持します。
- 二重送信を防ぎ、保存失敗時は入力・プレビュー・保存前のデータを残します。
- 別タブでデータが変わった場合はダイアログ内に案内し、古い内容での登録を止めます。
- 入力後のキャンセル・Escape・ページ移動では破棄を確認します。保存成功時は確認なしで閉じ、元のボタンへフォーカスを戻します。
- 登録成功時は件数・重複除外数を案内し、検索条件を解除して追加した単語を一覧に表示します。

UIからLocalStorageへ直接書き込まず、既存のProviderとRepositoryを経由しています。保存データのversion・既存の型構造・依存パッケージは変更していません。

### 手動で試す手順

1. 単語管理で単語帳を選び、検索語を入力します。学習状態を変え、件数と表示内容が変わることを確認します。
2. 「一括貼り付け」に上記の3行を入力し、「プレビューを表示」→「○語を登録する」で保存します。
3. 同じ内容を再度貼り付け、重複が除外されることを確認してキャンセルします。
4. 「CSV出力範囲」を選んで「CSV出力」を押します。
5. 別の単語帳を選び、「CSV取込」でそのファイルを選択します。見出しと文字コードを確認し、プレビューして登録します。
6. 元と同じ問題・答え・補足が新しい未学習の単語になっていることを確認します。
7. 答えの空欄や引用符の不正を含む入力では、エラーになって登録されないことを確認します。
