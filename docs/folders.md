# フォルダーによる階層管理

単語帳の中にフォルダーを作り、さらに単語と子フォルダーを登録できます。
例：`基本情報技術者 → テクノロジ系 → 基礎理論 → 2進数`。
PDF・画像などの添付ファイルは対象外です。

## 操作

- 単語帳を開き、「フォルダーを作成」で分類を追加します。フォルダーを開くと、さらに同じ操作で子フォルダーを作れます。
- 「単語を追加」、PCの一覧入力、一括貼り付け、CSV取込は、開いている場所に単語を追加します。
- 上部に表示する階層の名前を押すと、その場所に戻れます。
- 「単語の表示範囲」で、直下のみ／下の階層も含めるを選びます。検索とCSV出力もこの範囲に従います。
- 単語の移動ボタンで同じ単語帳内のフォルダーを選べます。内容・作成日時・学習状態を引き継ぎます。
- 学習テストを始める前に、この場所の単語と複数の子フォルダーをチェックボックスで選べます。選んだ子フォルダーは下の階層も含みます。途中再開と、結果の「まだ」をもう一度学習する操作も、開始時に選んだ範囲が対象です。
- 名前の変更と削除は各フォルダーのボタンで行います。削除は配下すべてが対象になり、確認画面にフォルダー数と単語数を表示します。

名前は前後の空白を除いて1〜80文字、深さは20階層までです。同名のフォルダーも作れます。
フォルダーそのものの移動は未対応です。単語は移動できます。
学習中の単語を移動・削除した場合は、その回の学習を終了します。単語に記録した学習状態は、移動後も引き継ぎます。

## 保存と既存データ

ログイン中のアカウントに、単語帳・フォルダー・単語をまとめて保存します。
以前の単語と学習状態はそのまま単語帳の直下に残ります。
アプリを開いたまま更新した場合は、ページを再読み込みしてください。

開発者向けの変更点は以下です。

- `AppData.version` は2です。`folders` に所属単語帳・親フォルダー・名前を保持します。
- 単語の `folderId` が未指定または `null` のときは単語帳直下です。学習セッションの `folderId` が未指定または `null` のときは単語帳全体が範囲です。
- 形式1は読み取り時に形式2として扱い、次の保存で書き込みます。読み取りだけで元データを書き換えず、ID・revision・学習状態を維持します。旧LocalStorageの取り込みも同じ検証を通します。
- サーバーは、存在しない親・別単語帳への参照・循環した親子関係・20階層を超えるデータを拒否します。
- 形式1の古い画面からの保存はHTTP 409で拒否し、階層が消える上書きを防ぎます。
- CSVは問題・答え・補足の3列です。階層情報は含まず、取り込み先のフォルダー内で重複を判定します。

実装の確認先：[`folderService.ts`](../src/services/folderService.ts)、[`validateAppData.ts`](../src/services/validateAppData.ts)、[`backend.ts`](../server/backend.ts)。

## 検証

自動テストでは、親子関係・作成・名前変更・移動・配下の削除・学習範囲・移行・不正データの拒否を検証しています。
隔離したテストアカウントとDBを使うブラウザー操作では、例の階層の作成、個別／一覧／一括追加、移動、未保存入力の保護、学習、再読み込み、再ログイン、削除の確認と取り消し、PCと320px幅での表示を確認しています。

確認先：[`folderService.test.ts`](../src/services/folderService.test.ts)、[`backend.test.ts`](../server/backend.test.ts)。
