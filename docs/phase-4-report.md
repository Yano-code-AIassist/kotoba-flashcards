# Phase 4 実装報告

更新日：2026-09-18

LocalStorageへの保存・読み込みを実装しました。保存した単語帳や単語は、ページを更新した後も復元されます。例えば「基本情報技術者」にRFPを追加して保存すると、同じブラウザで開き直しても続けて編集できます。

## 1. 実装した内容

### 保存先とデータ検証

- 画面は既存のProvider経由で操作し、保存先を `memoryRepository` から `localStorageRepository` に変更しました。画面へLocalStorageのアクセス処理は追加していません。
- 保存キー `kotoba:app` に、`version: 1`、`revision`、単語帳、単語、学習状態・日時、設定、学習セッションを1つのJSONで保存します。
- 進捗・件数は保存した単語から再計算します。例えば3語のうち1語が「覚えた」なら33％です。
- 保存に成功した後だけ共有状態と画面を更新し、revisionを1増やします。追加・編集・削除の各操作で保存するため、ブラウザ終了時の処理には依存しません。
- 読み込むJSONはまず `unknown` とし、version、revision、必須項目、文字数、状態値、UTC日時、ID重複、所属先、セッションの出題順と回答順を検証します。
- 保存キーが存在しない場合だけ初回と扱います。空文字、不正JSON、不正な所属などは自動初期化しません。
- version 1以外の正の整数は未対応形式として保持します。以前のPhaseはメモリ保存だったため、旧永続データからの移行処理はありません。

設定と学習状態・セッションの保存形式は対応済みです。設定変更画面・学習操作はまだ実装していません。これらの値の復元はテスト用データで確認しています。

### 保存・読み込みに失敗した場合

| 状況 | 対応 |
| --- | --- |
| 保存容量不足 | エラーと再保存の案内。フォーム入力・元の保存データを保持 |
| 保存領域へのアクセス禁止 | 空のホームへ進まず読み込みエラー。「もう一度読み込む」で再試行 |
| JSON破損・不正な形式 | 通常の編集を止め、元の文字列を保持 |
| 未対応のversion | 対応していない形式と案内し、上書きを防止 |
| 元データの退避 | 読み込み時の文字列を加工せずJSONファイルとしてダウンロード |
| 初期化 | 対象と削除の影響をダイアログで確認。初期フォーカスはキャンセル |
| 初期化中の変更 | 確認対象の元文字列と現在の保存値を照合。変わっていたら削除を拒否 |

初期化では `removeItem('kotoba:app')` だけを使用し、他のキーを残します。退避ファイルの自動取り込み・自動修復は今回の対象外です。

### 複数タブ

別タブで対象キーが変わるか削除されると、再読み込みの案内を表示して保存を停止します。画面や入力を勝手に差し替えません。保存直前にもrevisionと元の文字列を照合するため、通知がまだ届いていない変更や同じrevisionの置換も検知します。

未保存の単語入力があるときに「ページを再読み込み」を押すと、既存の離脱確認が働きます。キャンセルすれば入力を保持します。変更内容の自動統合は行いません。

LocalStorageでは厳密な同時編集を保証しません。照合と書き込みの間に別タブが書き込む競合は残るため、編集は1タブを基本とします。Web Storage仕様にも、共有状態のロックを前提にしないことが記載されています。[HTML Standard：Web Storage](https://html.spec.whatwg.org/multipage/webstorage.html)

### 手動確認

1. `npm run dev` で起動し、表示されたURLを開く。
2. 「基本情報技術者」を作成し、問題「RFP」、答え「Request for Proposal」を保存する。
3. ページを再読み込みし、単語を確認する。編集・削除後も再読み込みし、その結果が維持されることを確認する。
4. ブラウザを終了し、同じブラウザ・同じURLを開く。保存データを確認する。
5. 同じURLを2つのタブで開く。一方で単語を入力中に、もう一方で単語帳名を変更する。入力側に更新案内が出て、下書きが残ることを確認する。
6. 下書きを控えてから再読み込みする。変更後の単語帳名を確認する。

破損や容量不足の確認は普段使うデータで実施せず、単体テストまたは専用のテスト用ブラウザを使ってください。

### 保存先の範囲

LocalStorageはブラウザのオリジンごとに分かれます。開発用の `127.0.0.1:5173`、`localhost:5173`、異なるポートは別の保存先です。サイトデータの削除やプライベートブラウズの終了では保存内容が失われる場合があります。端末間の同期やクラウドバックアップはありません。[MDN：localStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage)

`storage` イベントは同じ保存領域を使う別文書の変更通知に利用しています。[MDN：storageイベント](https://developer.mozilla.org/en-US/docs/Web/API/Window/storage_event)
