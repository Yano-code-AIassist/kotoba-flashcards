# Phase 3 実装報告

更新日：2026-09-18

Phase 3として、単語帳を選び、単語を追加・編集・削除する機能を実装しました。引き続きメモリ保存を利用します。**ページを更新・閉じると、登録した単語帳と単語が消えます。**

## 1. 実装した内容

### 単語の管理と入力

- 「単語管理」から管理する単語帳を選択し、その単語帳の一覧へ進めます。
- 一覧の選択欄で単語帳を切り替えられます。単語帳が0冊、単語が0語の場合は作成・追加を案内します。
- 単語の新規追加・編集画面に、問題・答え・補足説明の入力欄を用意しました。
- 問題と答えは必須で、それぞれ2,000文字まで。補足説明は任意で5,000文字までです。
- 保存時は前後の空白を除き、内容内の改行を保持します。空欄や上限超過では項目の近くにエラーを表示します。長い文章を貼り付けても途中で切り捨てず、入力を保持して修正できるようにします。
- 新規単語は未学習として登録し、最終学習日時は未設定にします。
- 編集時は内容を更新し、ID・所属単語帳・作成日時・学習状態・最終学習日時を維持します。
- 一覧と編集画面から削除できます。削除前に対象の問題を確認するダイアログを表示します。
- 保存成功後に単語一覧へ戻り、一覧・ホーム・詳細の件数を更新します。

例えば「基本情報技術者」に、問題「RFP」、答え「Request for Proposal」、補足「提案依頼書」を登録できます。追加直後は登録単語数1、未学習1、覚えた0、進捗0％です。

### 画面移動と未保存入力の保護

| URL | 画面 |
| --- | --- |
| `#/manage` | 管理する単語帳を選択 |
| `#/decks/:deckId/words` | 選択した単語帳の単語一覧 |
| `#/decks/:deckId/words/new` | 単語を追加 |
| `#/decks/:deckId/words/:wordId/edit` | 単語を編集 |

単語フォームに未保存の変更がある場合、「キャンセル」や同じタブのリンク、ブラウザの戻る・進むで移動する前に破棄確認を行います。移動をキャンセルした場合は元のURLと入力内容を維持します。保存・削除が成功した後の移動では確認を抑止します。

ページ更新・終了については、未保存入力があるときだけ `beforeunload` によるブラウザの確認を要求します。これは一時保存データの永続化ではありません。

存在しない単語や、別の単語帳に所属する単語の編集URLには、対象が見つからない案内と戻り先を表示します。保存・削除の連打を防ぎ、保存失敗時は入力を保持します。

### 手動確認手順

1. `npm run dev` で起動し、「基本情報技術者」と「英単語」の2冊を作成する。「単語管理」で両方が選べることを確認する。
2. 「基本情報技術者」を選び、0語の案内から「最初の単語を追加」を開く。問題・答えを空欄や空白だけで保存し、エラーと入力欄のフォーカスを確認する。
3. 問題「RFP」、答え「Request for Proposal」、補足「提案依頼書」を保存する。一覧へ戻り、1語・未学習の表示と完了通知を確認する。ホームと詳細の件数も確認する。
4. 補足が空欄の単語を追加する。問題・答え・補足に改行がある例も保存し、一覧と再編集時に内容内の改行が残ることを確認する。
5. 入力欄の上限を確認する。問題・答えは2,000文字、補足は5,000文字。Enterは改行となり、意図せず保存されないことを確認する。
6. 登録した単語を編集する。内容が一覧に反映され、他の単語と登録件数が変わらないこと、未学習の表示が維持されることを確認する。学習済み状態・日時の維持はテスト用データでの単体テスト対象とする。
7. 一覧から削除ダイアログを開き、キャンセルで単語が残ることを確認する。再度開いて削除し、対象だけが消え、件数も減ることを確認する。編集画面からの削除も試す。
8. フォームに変更を加え、画面内の戻るリンク・「キャンセル」・ナビゲーションを操作する。破棄確認でキャンセルするとURLと入力が維持され、破棄を選ぶと移動できることを確認する。
9. 未保存入力がある状態でブラウザの戻る・進むを試す。キャンセル時はフォームを維持し、承認時は移動できることを確認する。保存成功後には破棄確認なしで一覧へ戻ることを確認する。
10. 単語帳を「英単語」に切り替え、「基本情報技術者」の単語が混ざらないことを確認する。存在しない単語IDや別単語帳の単語IDを編集URLへ指定し、編集できないことを確認する。
11. 横幅320px、768px、1024px以上で、入力欄・操作ボタン・長文・改行の表示と、下部ナビや固定操作部分による隠れを確認する。Tab / Shift+Tabで入力・ボタンを操作する。
12. 最後に、未保存入力がある状態でページ更新を試し、ブラウザの確認をキャンセルして入力が残ることを確認する。その後に更新を実行し、一時保存の単語帳と単語が消えることを確認する。

単体テストでは入力検証、作成・編集・削除のデータ整合性、学習状態の維持、関連セッションの扱い、URLの判定を確認しました。上記の手動手順でも動作を再確認できます。スマートフォン実機でのキーボード挙動は別途確認が必要です。
